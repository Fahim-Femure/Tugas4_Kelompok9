# Dashboard Energi Terbarukan

Aplikasi ini bertujuan untuk menampilkan informasi dan pemantauan ringkasan sumber energi terbarukan di Indonesia secara interaktif. Melalui aplikasi ini, pengguna dapat melihat statistik kapasitas, tingkat efisiensi, serta sebaran lokasi pembangkit energi ramah lingkungan dengan navigasi berbasis interaksi gesture.
